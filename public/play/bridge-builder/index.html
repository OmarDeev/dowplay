Keyboard: arrow keys move the cursor between points. Space picks the cursor point as the start of a beam. Move to a neighbouring point (or any point for a cable) and press Enter to build. Delete removes the beam between the start point and the cursor. Escape cancels. Number keys choose a material, E the eraser, Ctrl+Z undoes.
